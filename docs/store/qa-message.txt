This is 0.8.0 and replaces the 0.6.0 update that is still in QA; the published version is 0.5.3. The numbers in between were development steps that I did not submit: 0.6.0 added the memory card, 0.7.x a password strength rating, 0.8.0 a password report. Nothing was removed.

SailVault needs no account. To try it, pull down on the first page and choose "New database". The master password needs at least 15 characters and must not be too easy to guess: the app now rates it and refuses one rated Poor, such as "passwordpassword". A few random words work, for example "harbour window coffee planet". Then add entries from the pulley menu. The password report is under Settings > Password report.

Permissions: Documents and Downloads are used to add existing .kdbx databases and key files, save copies and read Bitwarden JSON exports the user picks. Removable media is new and is used to pick the same files from a memory card. Internet is used only for the optional Nextcloud sync (Settings > Sync with Nextcloud), which needs the user's own Nextcloud server; the app works fully without it. The sync login opens the Nextcloud login page in the browser (Nextcloud Login Flow v2).

Test databases with fake data are in the repository under core/tests/fixtures (password: sailvault-fixture).
