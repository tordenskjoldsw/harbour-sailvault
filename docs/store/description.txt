I wanted my passwords on my Sailfish phone, in a file I control, in an app that runs in the sandbox. That is SailVault. It keeps your passwords in a normal KDBX 4 file, the format of KeePass and KeePassXC, so the same file opens in KeePassXC on your computer. You need no account for it.

What you can do with it
- Open your KDBX 4 database with a master password, a key file or both. An older KDBX 3.1 file is turned into KDBX 4 when you add it, and your original stays as it is.
- Add, edit, move and delete entries and groups. Old versions of an entry and the recycle bin work as in KeePassXC.
- Search by title, user name, URL, notes and tags.
- Sync with your own Nextcloud. Change a password on the phone and it is on your computer, and the other way round. If both sides changed, SailVault merges them. Without a connection you keep working and it syncs later.
- No Nextcloud? Merge a copy of the database from a file instead.
- Coming from Bitwarden or Vaultwarden? Import your JSON export, with or without a password. Importing a newer export later updates the entries instead of doubling them.
- Create a new database and generate passwords. SailVault rates passwords the way KeePassXC does, for an entry and for a new master password, and refuses a master password that is too easy to guess.

What it does not do
- No fingerprint unlock and no autofill. I found no way to do either from an app in the Jolla Store.
- No one-time codes (TOTP). TOTP fields from KeePassXC are kept and shown as hidden fields, and KeePassXC still shows the codes from the same file.

How your passwords are protected
- You type the full master password every time. Nothing on the phone unlocks the database without it.
- Nothing decrypted is written to storage. When the database locks, the keys are wiped from memory. It locks after five minutes without use and after one minute in the background.
- A copied password is removed from the clipboard after 30 seconds.
- Databases and key files are kept in SailVault's private storage.
- Before a save replaces your database, SailVault opens the new file again to check it. The last three versions are kept as backups.
- SailVault only connects to the Nextcloud you set up, over https. If you do not set up sync, it connects to nothing. The Nextcloud app password is stored inside your encrypted database.

Permissions
- Documents and Downloads: to add databases, save copies and read imports.
- Removable media: to add databases and read imports from a memory card.
- Internet: only for the Nextcloud sync you set up.
