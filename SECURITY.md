# Security policy

SailVault holds passwords, so I take reports seriously. Please don't open a
public issue for a security problem.

## Reporting a vulnerability

- Preferred: [report it privately on GitHub](https://github.com/tordenskjoldsw/harbour-sailvault/security/advisories/new).
- Without a GitHub account: email sailvault-security@mailbox.org.

Include the SailVault version (shown on the About page), the Sailfish OS
version, the steps to reproduce and what an attacker gains. Use a test
database: never send me a real password or a real database.

I confirm that your report arrived, keep you posted while I work on a fix,
and credit you in the release notes unless you would rather stay anonymous.

## Supported versions

Only the latest release gets security fixes.

## Scope

What SailVault protects against, and what it does not, is in the
[threat model](docs/threat-model.md).
